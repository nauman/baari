# baari — compiled releases

Binary-only public mirror for [baari](https://github.com/nauman/baari-cli-releases). The
source repository is private and stays that way; this repo exists only to host
GitHub Releases (published by CI on every tagged release) and the install page.

- Install: see https://nauman.github.io/baari-cli-releases/
- Homebrew: `brew install nauman/tap/baari`
