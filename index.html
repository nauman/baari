baari

Cross-repo agent coordination — the ~/.agents registry and thread monitor.

Install

Via Homebrew:

brew install nauman/tap/baari

Without Homebrew:

curl --proto '=https' --tlsv1.2 -fsSL https://nauman.github.io/baari-cli-releases/install.sh | sh

Source

Binaries here are compiled from a private source repository and published on every tagged release. The binary ships generic mechanism only — no project-specific canon — configured per repo via .baari.yml.
