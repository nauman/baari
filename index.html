baari

One place to see what you owe a reply to — across every repo on your machine.

Working across several repos means coordination state is scattered: a note here, a thread there, a script in each project that only knows about itself. baari keeps a machine-local registry of the repos you work in and gives you one view over all of them.

Language- and framework-agnostic. It reads conventions in your repo, not your code — so it works the same whether a project is Rails, Go, Node, Python, or plain documentation.

Install

Via Homebrew:

brew install nauman/tap/baari

Without Homebrew:

curl --proto '=https' --tlsv1.2 -fsSL https://nauman.github.io/baari/install.sh | sh

What it does

baari status
Cross-repo view of what you owe a reply to, and what you're waiting on others for.
baari next
Just what's owed right now, across every registered repo — nothing else.
baari registry
List, prune, forget, or ignore the repos baari knows about. Repos register themselves the first time you run baari inside one — no manual setup step.
baari doctor
Validate machine and repo state: registry integrity, identity, and convention markers.
baari thread
Inspect and scaffold coordination threads, and flag ownership assigned to names that don't exist in the owning repo.
baari whoami
Show the identity baari resolves for "who is me", and where it came from.

Configuration

baari ships mechanism, not opinions. Checks read their thresholds from a .baari.yml in your repo root, so nothing project-specific is compiled into the binary. With no config file, checks run with zero allowances and warn rather than fail.
